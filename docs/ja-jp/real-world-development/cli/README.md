**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルで GitHub Copilot をエージェント型コーディングアシスタントとして利用できます。コードベースを調査し、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業の流れを保てます。

このワークショップでは、Tailspin Toys の1つの連続したワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価に対象を絞った変更を加え、転送されたブラウザーで確認して、最初のプル リクエスト (PR) を手動でマージします。
3. フィルター機能の Issue から開始し、Plan モードでアプローチを決め、Autopilot モードで構築して、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) server を追加し、ブラウザーでフィルター機能を確認します。
7. 品質保証 (QA) カスタムエージェントを作成して使用し、要件、カバレッジ、検証の証拠をレビューします。
8. フィルター機能の変更全体をレビューし、フィルター PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、cloud agent への任意の委任に役立つスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、PR は2つ作成します。1つ目は星評価、2つ目は指示、スキル、QA プロファイル、テストを更新したフィルター機能です。フィルター機能と品質に関するワークフローでは1つの会話とブランチを共有するため、各ツールを確認しながら、それまでの作業を活用できます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかのプランが設定された GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドラインの基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合、管理者が Copilot CLI を有効にしていることを確認してください。
